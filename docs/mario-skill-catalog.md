# マリオの全Skillと判断条件一覧

対象：`continuous-skills-v16`。2026-09-24 時点の実装。

[オントロジーと設計の解説](mario-ontology-and-design.md)に対応する実装リファレンスです。Jevに提示しうるSkillは19種類、複合Skill内部専用は2種類あります。応答待ち・着地保護などのローカル制御は別枠で記載します。

## この一覧の読み方

**「ジャンプしたら終わり」ではなく、「対岸に着地するなどの目的を達成するまで」がSkillです。** 成功条件は継続と終了の境界を作り、実行手順はその間の操作を決め、中断条件は前提が崩れたときの切り替えを決めます。成功条件だけで制御が自動的に生まれるわけではありません。

目的・対象・適用条件・達成条件は、ここでいう広義のオントロジーを構成します。ただし数値閾値はこの実験で調整した制御・戦略上の設定も含み、普遍的な世界の法則ではありません。

- 同じセルの条件は、特記がなければすべて満たす必要があります。
- `dx` は対象との横方向の差（正＝前方、負＝後方）、`dy` はコードの縦方向の差です。
- `vx` はマリオの横速度。X・Yはゲームから取得するマリオの座標です。
- 1タイル＝16px、f＝ゲームのフレーム。フレーム数とAPIの実時間は区別します。
- 成功＝実装の判定を満たしたこと。通常終了（completed）や判断を返すこと（yielded）は、目的達成の証明ではありません。
- `SkillSpec` は名前・上限・期待結果・パラメータを保持します。適用条件は `catalog()` と補助関数、終了条件は各制御クラスにも分散しています。

## 1. 共通条件

| 段階 | 条件・処理 |
|---|---|
| 候補生成前 | 死亡・クリア済みなら候補なし |
| 空中 | LandForwardとContinueJumpのみ。地上向け候補生成には進まない |
| 地上 | WaitForOpeningとSurveyを基本候補にし、条件を満たすSkillを追加 |
| 候補生成後 | 試行済み登録地点を除外。設定で無効化した序盤取得・フラワー訪問・射撃も除外 |
| 停滞 | 待機以外の候補があればWaitForOpeningとSurveyを除外 |
| 選択 | 候補が複数ならJevへ依頼。1つならAPIを呼ばず採用候補として返す |
| 応答採用 | 45f以内、死亡・クリアしていない、最新状態でも同じSkillが候補にあること。個別の対象照合も行う |
| 応答の優先順位 | 局所引き継ぎが動作を継続中、または着地保護が有効なら応答を採用しない |
| 実行中の共通失敗 | 死亡・残機減少。開始時がsmall以外で、現在smallになった場合も失敗 |
| 安全介入 | 着地保護が新たに引き継いだら、実行中Skillを中断 |
| 全体終了 | クリア・死亡・環境終了・手動終了などでプレイを終了 |

共通ダメージ検知は、例えばfireball→tallまで網羅した一般的な無傷の証明ではありません。以下の成功条件は、実際のコードが確認する範囲を示します。

## 2. 移動・待機・空中：5種類

| Skill／目的 | 候補条件 | 制御 | 成功・終了・中断 |
|---|---|---|---|
| **Advance**／安全区間の前進 | 地上。下の床が見える。前方0〜80px・abs(dy)<32の敵なし。3タイル以内の障害物なし。4タイル以内の穴なし | 右＋走行 | 空中または前述の危険で判断を返す。120fで通常終了 |
| **Survey**／短く観察 | 地上の基本候補 | 無入力。慣性は残る | 8fで通常終了。後方接近、または前方0〜40px・abs(dy)≤16の敵で判断を返す |
| **WaitForOpening**／制動して再観察 | 地上の基本候補 | vx>1なら左、それ以外は無入力 | 24fで通常終了。敵条件はSurveyと同じ |
| **LandForward**／前進しながら着地 | 空中 | 右入力 | 着地Xが開始X以上なら成功、手前なら失敗。72f上限 |
| **ContinueJump**／上昇を維持して着地 | 空中 | 上昇中は右＋ジャンプ、それ以外は右 | 着地Xが開始X以上なら成功、手前なら失敗。72f上限 |

WaitForOpeningは、特定の敵の通過完了を判定するSkillではなく、現在は短時間の制動と再観察です。

## 3. 敵への対応：3種類

| Skill／目的 | 候補条件 | 制御 | 成功・終了・中断 |
|---|---|---|---|
| **JumpOverEnemy**／敵を越える | 地上。前方16〜128px・abs(dy)<32の敵。該当する最も近い敵を対象にする | 目標X＝選択時の敵X＋24。Aを解除後、右＋走行＋ジャンプを24f保持し、その後も前進 | 空中を経て目標X以上に着地で成功、手前なら失敗。80f上限 |
| **EvadeRearEnemy**／後方接近の回避 | 地上。後方80px以内、abs(dy−8)≤16、相対速度が接近方向、推定接触時間24f以内 | 前方3タイルに床と上2タイル分の空間があり、前方0〜64px・abs(dy−8)≤24の敵なし、接触まで8f超なら走る。それ以外は垂直ジャンプ。1〜2タイル先に高さ1〜3段の障害物があり穴が観測されていなければ、高さを得て障害物上へ移動 | 接近がなくなれば通常終了。回避ジャンプ後の着地で通常終了。ジャンプ開始前の足場喪失で中断。80f上限 |
| **FireAtEnemy**／遠方へ射撃 | 地上・fireball・abs(vx)≤1・周囲の床あり。dx=−48〜48かつabs(dy)<32の敵なし。3タイル以内の障害物なし。前方64〜144px・abs(dy−8)≤16にクリボー／緑・赤ノコノコ | 右を向いてBを解除。12f周期で、弾が2発未満なら発射。その間はBを解除 | fireball・接地・床の条件喪失で中断。dx=−40〜48・abs(dy)<32の敵で回避へ返す。対象が48px未満、またはabs(dy−8)>24でも判断を返す。対象消失・72f経過は通常終了。消失を撃破と断定しない |

後方の接触時間＝`max(0, 後方距離−12) / 相対接近速度`。回避ジャンプは24f保持し、その後着地へ移ります。障害物へ逃げる場合は、障害物の高さ＋8px以上になってから横移動します。

JumpOverEnemyの成功は目標位置への着地と共通失敗条件に基づきます。敵の撃破や、着地後も安全であり続けることを確認しているわけではありません。

## 4. 地形と障害物：8種類

「穴越え可能」は、対岸が見えていて観測幅が4タイル以下という推定です。軌道の成功保証ではありません。「段＋穴パターン」は、1タイル先に高さ1段の障害物、2〜3タイル先に穴、かつ穴越え可能という条件です。

| Skill／目的 | 候補条件 | 制御 | 成功・終了・中断 |
|---|---|---|---|
| **ApproachObstacle**／離陸位置へ接近 | 地上。障害物が2〜4タイル先、高さ1〜3段。床が見える。穴なし、または穴が障害物より1タイル超先。dx=−16〜障害物距離×16＋32に敵なし | 右へ歩き、障害物の16px手前以降で制動 | その位置でabs(vx)≤1なら成功。空中・床不明・障害物以前の穴・dx=−16〜48の敵で中断。後方接近で判断を返す。90f上限 |
| **ClimbStep**／1段上へ着地 | 地上。障害物1〜2タイル先、高さ1段。床が見える。0≤dx<48・abs(dy)<32の敵なし。階段横断パターンでも段＋穴パターンでもない | 目標X＝段左端＋8、目標Y＝開始Y＋16。保持24f | 目標X以上かつ目標Y−2以上への着地で成功。その他の着地は失敗。80f上限 |
| **CrossGap**／対岸へ着地 | 地上。穴が4タイル以内。穴越え可能。段＋穴パターンではない | 穴の16px手前まで助走。助走中にA解除。保持30f、その後も右＋走行。目標＝対岸＋8px | 目標以上への着地で成功、手前は失敗。離陸前の足場喪失・穴の端通過で中断。120f上限 |
| **ClimbThenCrossGap**／頂上への着地後に穴越え | 地上。段＋穴パターン。abs(vx)≤1 | PrecisionClimb→成功確認→CrossGapへ、APIを待たず切り替え。内部CrossGapの上限110f | 両方成功で成功。段上への着地時に穴の開始X以上なら失敗。内部結果を引き継ぐ。全体200f上限 |
| **CrossStaircase**／階段を上り谷を横断 | 地上。dx=−32〜160に敵なし。グリッド内の自分と床を確認。1タイルずつ上がる階段があり高低差1〜3段。その先に幅1〜3タイルの低い区間があり、対向側に同じ高さの頂上が見える | 内部ClimbStep後に頂上を確認し、CrossPlatformへ切り替え | 切り替え時にXが頂上左端−2以上・＋16未満、Yが頂上Y−2以上でなければ失敗。横断成功で全体成功。内部結果を引き継ぐ。180f上限 |
| **EscapeValley**／4段の壁から脱出 | 地上。1タイル先に高さ4段の障害物。dx=−48〜96に敵なし。後方1タイルに床、その上4タイルに障害物なし | 壁の28px手前へ後退、16px手前まで助走しvx≥1で跳ぶ。40f保持。目標＝壁左端＋2 | 目標以上に着地で成功。壁の40px手前より後退・離陸前の足場喪失・abs(dx)<32かつabs(dy)<32の敵で中断。180f上限 |
| **ClearObstacle**／2〜3段の障害物を越える | 地上。グリッドで自分と床を確認。障害物1タイル先、高さ2〜3段、abs(vx)≤1。後方2列に床と上3段分の空間。障害物幅3タイル以下。障害物後方3列に同じ高さの床と上4段分の空間。自分の40px後方〜障害物右端＋48pxに敵なし | 現在の候補では現在位置付近から離陸。離陸Xの−2pxを許容。保持30f。障害物上に着地したら上を移動。目標到達後は制動 | 障害物右端＋2〜40px、開始Yとの差2px以内に着地で成功。障害物上の許容着地は継続。それ以外で障害物左端以上に着地した場合は失敗。abs(dx)<24・abs(dy)<24の敵で中断。後退時の足場喪失で中断。180f上限 |
| **RecoverObstacle**／後退して跳び直す | 地上。3タイル以内に障害物。後方2列に床と上3段分の空間。dx=−48〜16に敵なし | 12f後退→12f助走→A解除→30f跳躍保持。目標＝開始X＋32 | 目標以上に着地で成功。後退中の足場喪失・後方条件不成立・開始X−28未満で中断。後方接近、または前方0〜40px・abs(dy)≤16の敵で判断を返す。100f上限 |

ClearObstacleの障害物上の許容着地は、Xが障害物左端−2〜右端＋12、Yが開始Y＋障害物高さ×16−4以上の場合です。上を渡る制御は障害物右端＋8まで右移動を行います。

段＋穴パターンの成立時は、速度条件によりClimbThenCrossGapが候補にならなくても通常のClimbStep・CrossGapは抑制されます。候補間の条件の隙間は、継続的な検証対象です。

## 5. アイテム取得：3種類

| Skill／目的 | 候補条件 | 制御 | 成功・終了・中断 |
|---|---|---|---|
| **CollectPowerup**／近くの観測済み強化を取得 | 地上、abs(vx)≤1。dx=−48〜96に敵なし。自分の列〜前方4列に同じ高さの床と上3段分の空間。smallならキノコ、tallならフラワーが0〜48px先、abs(dy−8)≤12 | 右移動。毎f対象slot・kindと経路を再確認。再確認時は自分の移動速度で不適格にならないよう補正 | small→tall/fireball、tall→fireballで成功。対象消失・経路変化・対象不一致で中断。60f上限 |
| **VisitOpeningPowerup**／序盤の登録ブロックを訪問 | small・地上・X=280〜416。Y=75〜83、またはX=320〜380・Y=139〜147で3タイル以内に穴なし。登録地点が未使用。周囲の床あり、または上記高所条件。dx=−64〜112・abs(dy)<32の敵なし。ワールドX=404から64px未満に敵なし | 必要なら右へ降りる。X=332±3、abs(vx)≤0.4へ合わせ、A解除→20fジャンプ。観測したキノコの位置へ追従。追従目標Xを280〜404に制限、差が6px超なら移動 | tall/fireball化で成功。Xが264〜432の外、dx=−40〜64・abs(dy)<32の敵、必要な床の喪失で中断。降下時はX=404周辺の敵も中断条件。位置合わせ中の未使用条件喪失、観測後のアイテム消失で中断。480f上限 |
| **VisitFlower**／2か所目でフラワー取得 | tall・地上・X=1176〜1344。Y=75〜83または139〜147。登録地点が未使用。下の床が見える。dx=−64〜96・abs(dy)<40の敵なし | 下表の段階で実行 | fireball化で成功。tall喪失・死亡で失敗。Xが1170〜1348の外、dx=−64〜80・abs(dy)<40の敵、床・対象条件変化で中断。出現待ち100f超、屋根上への移動でフラワー消失の場合も中断。跳躍後Y<120に着地なら失敗。全体550f上限 |

周囲の床の確認 `safe_floor()` は、グリッド内で確認できる自分の2列後ろ〜4列先に床が連続することです。グリッド端では範囲を切り詰めます。低い天井まで確認するCollectPowerupの条件とは異なります。

| VisitFlowerの段階 | 継続・遷移条件 |
|---|---|
| 右へ降下 | 開始Y>100ならこの段階。X=1298方向へ移動。接地かつY<90で次へ |
| 待機地点へ | X=1290±3、abs(vx)≤0.4へ。接地中は待機地点の先1列まで床があることを確認 |
| 経路を待つ | 制動し、敵のワールドXが1160〜1328の範囲からいなくなるまで待つ |
| ブロック下へ | 未使用のままであることを確認。X=1244±3、abs(vx)≤0.4へ位置合わせ |
| 叩く | ジャンプを20f保持 |
| 出現確認 | fire_flowerを観測したら次へ。100f超の未確認で中断 |
| 屋根ジャンプの準備 | X=1284付近へ移動。位置合わせ完了・接地・Y≤90で次へ |
| 屋根へ跳ぶ | 最初の30fはジャンプ。Y≥125なら左ジャンプ。その後、花が右2px超なら右、左2px超なら左、それ以外無入力 |
| 完了確認 | どの段階でもfireball化を確認すれば成功 |

登録場所はWorld 1-1 / area 1のX=336と1248、ブロック画面Y=144です。smallならキノコ、tall/fireballならフラワーという条件付きの配置知識です。対象ブロックとのX差が−96〜128pxのときRAMを読み、0xC1を未使用、0xC4を使用済み、それ以外をunknownとします。確認範囲外はunobservedです。座標を知っているだけで未使用・出現・取得を断定しません。

## 6. 複合Skillの内部専用：2種類

| Skill／目的 | 呼び出し条件 | 制御・終了 |
|---|---|---|
| **PrecisionClimb**／飛び出さず頂上へ | ClimbThenCrossGap開始時 | 初回無入力、24fまで垂直ジャンプ、その後右方向を追加。保持30fまで。目標X＝段左端＋2、目標Y＝開始Y＋16。目標X以上・目標Y−2以上に着地で成功。90f上限 |
| **CrossPlatform**／頂上間の横断 | CrossStaircaseで頂上到達確認後 | A解除後24f保持の前方走行ジャンプ。その後も前進。対向側頂上左端＋8以上に着地で成功。90f上限 |

ClimbStepとCrossGapも内部で再利用しますが、上の19種類と同じ名前なので重複して数えません。

## 7. 応答待ちと安全のローカル制御

| 制御 | 発動条件 | 動作・終了 |
|---|---|---|
| **AwaitDecision** | 応答待ちなど、通常Skillの入力がない場面 | 空中は上昇中に右＋ジャンプ、それ以外は右。地上はvx>1なら左制動、それ以外無入力 |
| **後方の局所回避** | 地上で後方接近条件成立 | RearEvadeを実行。回避継続中は返ってきたAPI応答を採用しない |
| **前方の緊急ジャンプ** | 地上。前方0〜48px、abs(dy)≤16の敵 | 必要ならA解除、ジャンプ30f後も前進。着地・死亡・クリア・80fで継続状態解除 |
| **段差を降りる際の着地保護** | 前方2列以内に低い床が見え、dx=−8〜96・dy=24〜88の敵がいる。予定入力が右・走行・左・無入力 | 元Skillを中断。A解除→前方ジャンプ30f→前進。着地・死亡・クリア・90fで解除。底の見えない穴には適用しない |
| **下降時の着地位置補正** | 空中で上昇していない。着地まで1〜24fと推定できる。着地高さが分かり、予定入力での敵との距離が24px未満 | 無入力・左・右を比較。同じ床へ着地すると推定できる候補の最大距離を選び、4px以上改善するときだけ変更 |
| **停滞回復** | 最大到達Xが8px以上更新されず、12判断または180f経過。回復未試行 | 候補内からEscapeValley→ClearObstacle→RecoverObstacleの順に選びローカル実行。直接回復は一度のみ |

着地予測は観測した敵の高さと速度を使う推定です。保証された物理シミュレーションではありません。通信エラーは種別を記録して実行を終了し、無条件リトライはしません。

## 8. API応答時の対象照合

共通の期限・生存・最新候補への適合に加え、次を確認します。

| Skill | 追加照合 |
|---|---|
| JumpOverEnemy | slot・kind一致、目標X変化24px以内 |
| CollectPowerup / FireAtEnemy / EvadeRearEnemy | slot・kind一致 |
| ApproachObstacle / EscapeValley | 障害物左端一致 |
| ClearObstacle | 障害物左端一致、現在Xが指定離陸Xの±2px以内 |
| ClimbStep | 段X・目標Y一致 |
| CrossGap | 穴の開始・終了X一致、目標X変化24px以内 |
| ClimbThenCrossGap | 段X・穴の開始終了X・目標Y一致 |
| CrossStaircase | 頂上X・対向側X・頂上Y一致 |
| RecoverObstacle | 障害物左端変化24px以内 |
| その他 | 最新状態で同じSkillが候補にあること。上記以外の個別照合なし |

slotは内部スロットで、永久的な個体IDではありません。また応答後の再検証はcatalogを使い、候補生成後の追加フィルタすべてを再実行するものではありません。
